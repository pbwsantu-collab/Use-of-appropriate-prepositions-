# Appropriate Prepositions — Study & Practice (Bilingual)

**Live:** https://pbwsantu-collab.github.io/Use-of-appropriate-prepositions-/

Bilingual (English + বাংলা) study, teaching & practice companion for *Appropriate Prepositions*.

## Features
- Concepts with full Bengali translation
- Language toggle: English / বাংলা / Mixed
- Browsable Word List (~870 entries)
- Practice drills
- Question Bank builder (printable worksheets)
- Offline PWA support

## Files
- `index.html` – structure & bilingual UI
- `style.css` – styles + language modes
- `script.js` – data + logic
- `manifest.json` + `sw.js` – Progressive Web App
